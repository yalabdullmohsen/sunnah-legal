# sunnah-legal

الصفحات القانونية لتطبيق سُنّة: سياسة الخصوصية وصفحة الدعم.

## الملفات

`src/` المصدر، و`build.mjs` يولّد منه `privacy.html` و`support.html`، و`config.js` فيه المتغيرات (مثل بريد الدعم).

`counter/` صفحة تحويل قديمة إلى islamkwt.com، تبقى حتى لا تنكسر الروابط القديمة.

## النشر

يُنشر تلقائيًا عبر GitHub Pages من الفرع `main`. لا تحذف المستودع ولا تغيّر اسمه، فروابط الخصوصية والدعم في App Store تعتمد عليه.
